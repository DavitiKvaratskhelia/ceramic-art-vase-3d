# Ceramic Art Vase — ინტერაქტიული 3D

ხელით მოხატული კერამიკული ვაზის (თეთრი, ბზინვარე ჭიქური წვრილი ნაცრისფერი ხაზებით და გვერდზე შავ-ნაცრისფერი ფუნჯის მონასმების ვერტიკალური ზოლით) ინტერაქტიული 3D ვიზუალი ბრაუზერისთვის. აგებულია [Three.js](https://threejs.org/)-ით (r169), ერთ HTML ფაილში. გარე 3D მოდელი ან ტექსტურა არ გამოიყენება: გეომეტრიაც და მოხატულობაც კოდით იქმნება, ფიქსირებული seed-ით, ამიტომ ყოველ ჩატვირთვაზე ერთნაირია.

**საიტი:** https://ceramic-art-vase-3d.vercel.app

## 3D ფაილი

| ფაილი | შიგთავსი |
|---|---|
| `ceramic-art-vase.glb` | ვაზა: გარე მოხატული ზედაპირი, შიდა კედელი, მოუჭიქავი ქუსლი, 3 გამჭვირვალე სადები |

glTF 2.0 binary, ერთეული მეტრი (ზომა ≈ 241 × 343 × 241 მმ), სადებები y = 0-ზეა. ტექსტურები: base color + normal map (4096 px, JPEG), PBR metallic-roughness. იხსნება Blender-ში, Windows 3D Viewer-ში, https://gltf-viewer.donmccurdy.com-ზე და სხვაგან.

## გაშვება

- **ლოკალურად:** საქაღალდეში გაუშვით `npx serve .` ან `python -m http.server` და გახსენით მითითებული მისამართი.

საჭიროა ინტერნეტი, რადგან Three.js და შრიფტი CDN-დან იტვირთება. საჭიროა WebGL 2-ის მხარდაჭერა.

## შენიშვნები

- რეფერენსი: 18 ფოტო (წინიდან, გვერდებიდან, ზემოდან, ქვემოდან). ვაზას გამოქვეყნებული ზომები არ აქვს, ამიტომ **ზომები ფოტოებიდან არის შეფასებული**: პროპორციები გაზომილია პირდაპირ ხედებზე (სიმაღლე ≈ უდიდესი დიამეტრის 1.42-ჯერ, ყელი ≈ 0.61, ქუსლი ≈ 0.44), ხოლო აბსოლუტური მასშტაბი — ქუსლზე მიწებებული სადებებით (≈ 12.7 მმ). შედეგი: სიმაღლე ≈ 341 მმ, უდიდესი დიამეტრი ≈ 241 მმ (სიმაღლის ≈ 65%-ზე), ყელი ≈ Ø148 მმ, პირი ≈ 10 მმ სისქის, ქუსლი ≈ Ø106 მმ, კედელი ≈ 9 მმ. რეალური ზომა შეიძლება რამდენიმე სანტიმეტრით განსხვავდებოდეს.
- მოხატულობა: შავი ზოლი (ცენტრში ≈ ±40°) ჰორიზონტალური მონასმებისგან შედგება, წვეტიანი, „ბუმბულისებრი“ ბოლოებით და ნაცრისფერი კიდეებით; ზემოთ ოდნავ მარჯვნივ არის გადახრილი, როგორც ფოტოებზე. ზოლის თავზე თხელი მოყავისფრო-ნაცრისფერი მონასმია. დანარჩენი ზედაპირი თეთრია წვრილი ნაცრისფერი წრიული ხაზებით. ცალკეული მონასმები პროცედურულია, ანუ ფოტოს მონასმების ზუსტი ასლი არ არის.
- ქუსლი მოუჭიქავი თეთრია, ჩაღრმავებული ძირით და უხეში რგოლით; ქვეშ 3 გამჭვირვალე სადებია. შიგნით ვაზა ღია ნაცრისფერი ჭიქურითაა დაფარული.
- ეს არ არის 3D სკანერით მიღებული ზუსტი ციფრული ასლი.
